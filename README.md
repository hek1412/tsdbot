# TSD Task Manager Bot

Система управления задачами с веб-интерфейсом и Telegram-уведомлениями для отслеживания служебных поручений (ТСД/указаний).

## Основные возможности

- 📊 Веб-интерфейс на базе AG-Grid для управления задачами в полноэкранном режиме
- 📅 Автоматические уведомления в Telegram (каждый день в 9:00)
- 🔄 Повторяющиеся задачи (ежедневно, еженедельно, ежемесячно, ежегодно)
- 📎 Загрузка и хранение файлов для задач
- 📊 Группировка задач по месяцам с разделителями
- ✅ Активация/деактивация задач
- 📥 Импорт задач из CSV
- 🔔 Поддержка нескольких Telegram-чатов для уведомлений

## Технологии

- **Backend**: Flask 3.1.0, SQLite
- **Frontend**: AG-Grid Community 31.0.3, Vanilla JavaScript
- **Уведомления**: Telegram Bot API
- **Планировщик**: APScheduler
- **Контейнеризация**: Docker + docker-compose

## Описание файлов

### Корневые файлы

#### `run.py`
**Назначение**: Точка входа приложения
**Функции**:
- Инициализация Flask-приложения
- Запуск веб-сервера на порту 5000

#### `config.py`
**Назначение**: Централизованная конфигурация
**Переменные**:
- `TELEGRAM_BOT_TOKEN` - токен Telegram-бота
- `TELEGRAM_CHAT_IDS` - список chat_id для уведомлений (поддержка нескольких чатов)
- `DATABASE_PATH` - путь к базе данных SQLite
- `SCHEDULER_HOUR/MINUTE` - время отправки уведомлений (по умолчанию 9:00)
- `SECRET_KEY` - секретный ключ Flask

#### `import_csv.py`
**Назначение**: Утилита импорта задач из CSV
**Использование**: `python import_csv.py <путь_к_csv>`
**Формат CSV**: `номер_тсд;название;кому_представляется;срок_представления;примечания;дата_доклада;флаг`
**Функции**:
- `parse_date()` - парсинг дат в форматах DD.MM.YYYY, DD.MM, YYYY-MM-DD
- `import_csv()` - импорт задач с валидацией и подсчетом статистики

#### `.env`
**Назначение**: Переменные окружения
**Пример**:
```env
TELEGRAM_BOT_TOKEN=7392170931:AAFEd62e8KmGzH0QjxevQqdRN9GKKrPkl1Y
TELEGRAM_CHAT_ID=-5220813768,788956584
```
Поддерживает несколько chat_id через запятую.

#### `Dockerfile`
**Назначение**: Образ Docker для приложения
**Включает**:
- Python 3.11-slim
- Установку зависимостей
- Настройку рабочей директории
- Экспозицию порта 5000

#### `docker-compose.yml`
**Назначение**: Оркестрация контейнеров
**Настройки**:
- Монтирование volume для БД и файлов
- Проброс порта 5000
- Автоматический перезапуск

### Директория `app/`

#### `app/__init__.py`
**Назначение**: Фабрика приложения Flask
**Функции**:
- Создание экземпляра Flask
- Инициализация базы данных
- Регистрация blueprints
- Запуск планировщика уведомлений

#### `app/models.py`
**Назначение**: Модель данных и работа с SQLite
**Класс**: `TaskDB`
**Основные методы**:
- `init_db()` - создание таблицы tasks
- `get_all()` - получение всех задач
- `get_by_id(task_id)` - получение задачи по ID
- `create(data)` - создание задачи
- `update(task_id, data)` - обновление задачи
- `delete(task_id)` - удаление задачи
- `delete_with_children(task_id)` - удаление задачи с повторами
- `update_recurrence(task_id, data)` - обновление повторяющейся задачи
- `create_recurring_tasks(data)` - создание серии повторяющихся задач
- `get_tasks_for_notification()` - получение задач для уведомлений (сегодня + завтра)
- `mark_sent(task_ids)` - отметка задач как отправленных
- `add_file(task_id, filename)` - добавление файла к задаче
- `remove_file(task_id, filename)` - удаление файла

**Особенности**:
- Маппинг полей: `исполнитель` ↔ `кому_представляется`, `дата_выполнения` ↔ `дата_доклада`
- Автоматическая миграция схемы БД
- Поддержка JSON для хранения списка файлов

#### `app/routes.py`
**Назначение**: REST API endpoints
**Маршруты**:

**Задачи**:
- `GET /api/tasks` - получить все задачи
- `POST /api/tasks` - создать задачу
- `GET /api/tasks/<id>` - получить задачу по ID
- `PUT /api/tasks/<id>` - обновить задачу
- `DELETE /api/tasks/<id>` - удалить задачу
- `DELETE /api/tasks/<id>/with-children` - удалить задачу со всеми повторами
- `PUT /api/tasks/<id>/update-recurrence` - обновить повторяющуюся задачу
- `POST /api/tasks/recurring` - создать серию повторов
- `DELETE /api/tasks/clear` - удалить все задачи

**Файлы**:
- `POST /api/tasks/<id>/files` - загрузить файл
- `GET /api/tasks/<id>/files/<filename>` - скачать файл
- `DELETE /api/tasks/<id>/files/<filename>` - удалить файл

**Прочее**:
- `GET /` - главная страница
- `POST /api/test-notify` - тестовая отправка уведомлений

**Настройки**:
- `UPLOAD_FOLDER = '/data/uploads'` - папка для файлов
- Допустимые расширения: pdf, doc, docx, txt, xlsx, xls, png, jpg, jpeg, gif

#### `app/bot.py`
**Назначение**: Telegram-бот для отправки уведомлений
**Функции**:
- `send_telegram_message(text)` - отправка сообщения во все чаты из `TELEGRAM_CHAT_IDS`
- `format_tasks_message(tasks)` - форматирование красивого HTML-сообщения с задачами
- `notify_today_tasks(db)` - отправка уведомлений о задачах на сегодня и завтра

**Формат уведомления**:
```
🔔 Задачи на СЕГОДНЯ:

✅ №ТСД-123 — Название задачи
   👤 Кому: Иванов И.И.
   📅 Дата доклада: 2026-01-29
   📝 Срок: 10:00
   💬 Примечания

━━━━━━━━━━━━━━━━━━━

⏰ Напоминание: задачи на ЗАВТРА:
...
```

#### `app/scheduler.py`
**Назначение**: Планировщик автоматических уведомлений
**Функции**:
- `init_scheduler(db)` - инициализация APScheduler
- Запуск `notify_today_tasks()` каждый день в 9:00 (настраивается через `SCHEDULER_HOUR/MINUTE`)

#### `app/templates/index.html`
**Назначение**: HTML-шаблон веб-интерфейса
**Структура**:
- Fullscreen layout (контейнер на всю высоту экрана)
- Кнопки управления: "+Задача", "Очистить все", "Тестовое уведомление"
- AG-Grid контейнер
- Модальное окно для создания задачи
- Подключение AG-Grid Community 31.0.3 и custom JS/CSS

## База данных

**SQLite**: `/data/tasks.db`

**Таблица `tasks`**:
```sql
id INTEGER PRIMARY KEY
номер_тсд TEXT            -- Номер ТСД/указания
название TEXT             -- Название задачи
исполнитель TEXT          -- Кому представляется
дата_выполнения TEXT      -- Дата доклада (YYYY-MM-DD)
срок_представления TEXT   -- Срок представления
примечания TEXT           -- Примечания
флаг INTEGER              -- Активность (0/1)
отправлено INTEGER        -- Отправлено уведомление (0/1)
повтор_тип TEXT           -- Тип повтора (none/daily/weekly/monthly/yearly)
повтор_интервал INTEGER   -- Интервал повтора
повтор_до TEXT            -- Повторять до даты
родитель_id INTEGER       -- ID родительской задачи для повторов
файлы TEXT                -- JSON-массив имен файлов
created_at TEXT           -- Дата создания
```

## Настройка Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота
3. Узнайте chat_id (добавьте бота в чат/группу и получите ID через [@userinfobot](https://t.me/userinfobot))
4. Укажите в `.env`:
```env
TELEGRAM_BOT_TOKEN=ваш_токен
TELEGRAM_CHAT_ID=chat_id_1,chat_id_2,chat_id_3
```

Поддерживается несколько чатов через запятую.

## Повторяющиеся задачи

При изменении типа повтора для существующей задачи:
- Удаляются все старые дочерние задачи
- Создаются новые повторы на год вперед (или до даты `повтор_до`)
- Родительская задача сохраняет свой ID

При удалении повторяющейся задачи (родителя):
- Удаляются все дочерние задачи
- Отображается двойная иконка 🗑️🗑️
